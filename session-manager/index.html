＋ 新对话
说明: 状态徽章 · Resume / 切过去 状态徽章(hook 实时记账 + 进程存活双重判定): ● 正在跑 = 你刚提交、Claude 在干活; ● 等你选择 = 卡在权限/选择上; ● 等你回复意见 = 这一轮结束, 它在问你或还有下一步; ○ 可以关了 = 活干完了、没要你回的(由话题脉络判定)。没有徽章 = 进程已经没了(窗口关了)。
点 Resume 弹一个新 Windows Terminal 窗口, 自动 cd 回原目录再 claude --resume。 这个对话已经开着的话, 同一个按钮变成「⇥ 切过去」, 直接切到那个窗口而不是再开一个 —— 两个窗口 resume 同一个对话会写同一份记录、互相覆盖。真开了多个时, 状态条下面会把它们 一个个列出来, 每个后面带「切过去 / ✕ 关闭」。标题和注释填完点别处自动保存。
